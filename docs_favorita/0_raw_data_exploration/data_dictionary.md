## Типы данных

| Категория                 | Тип                                                 | Размер / диапазон                                       | Когда использовать                                                                                            |
| ------------------------- | --------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **Целые**                 | `SMALLINT`                                          | 2 байта, ±32 767                                        | Малые справочные коды, если экономия места действительно важна                                                |
| **Целые**                 | `INTEGER` / `INT`                                   | 4 байта, ±2,1 млрд                                      | Счётчики, количества, ID в небольших таблицах                                                                 |
| **Целые**                 | `BIGINT`                                            | 8 байт, ±9,2·10¹⁸                                       | Первичные ключи по умолчанию, таймстемпы в мс, крупные счётчики                                               |
| **Точные дробные**        | `NUMERIC(p,s)` / `DECIMAL(p,s)`                     | До 1000 знаков в PG                                     | Деньги, бухгалтерия, всё, где ошибка округления недопустима                                                   |
| **Приближённые**          | `REAL` / `FLOAT4`                                   | 4 байта, ~6 знаков                                      | Данные сенсоров, где точность не критична                                                                     |
| **Приближённые**          | `DOUBLE PRECISION` / `FLOAT8`                       | 8 байт, ~15 знаков                                      | Научные расчёты, метрики, признаки для ML                                                                     |
| **Строки**                | `CHAR(n)`                                           | Фиксированная длина, дополняется пробелами              | Почти никогда; разве что строго фиксированные коды (ISO-коды стран)                                           |
| **Строки**`VARCHAR(n)`    | Переменная длина до n                               | Когда ограничение длины — бизнес-правило (телефон, код) |                                                                                                               |
| **Строки**                | `TEXT`                                              | Без ограничения                                         | Основной строковый тип в PG; в MySQL с оговорками по индексам                                                 |
| **Логический**            | `BOOLEAN`                                           | true / false / NULL                                     | Флаги (в MySQL это алиас `TINYINT(1)`, в SQL Server — `BIT`)                                                  |
| **Дата и время**          | `DATE`                                              | Только дата                                             | Даты рождения, сроки, отчётные дни                                                                            |
| **Дата и время**          | `TIME`                                              | Только время                                            | Расписания («открыто с 9:00»)                                                                                 |
| **Дата и время**          | `TIMESTAMP`                                         | Дата и время без зоны                                   | Локальное «настенное» время без привязки к поясу (редко нужно)                                                |
| **Дата и время**          | `TIMESTAMPTZ`                                       | Дата и время, хранится в UTC                            | События, логи, created_at — выбор по умолчанию                                                                |
| **Дата и время**          | `INTERVAL`                                          | Промежуток времени                                      | Длительности, сдвиги дат (`now() - interval '7 days'`)                                                        |
| **Бинарные**              | `BYTEA` (PG) / `BLOB` (MySQL) / `VARBINARY` (MSSQL) | Произвольные байты                                      | Хэши, небольшие бинарные данные. Файлы лучше в объектном хранилище, в БД — путь                               |
| **Идентификаторы**        | `UUID`                                              | 16 байт                                                 | Распределённая генерация ID, публичные ID. Для ключей лучше UUIDv7 (упорядочен по времени)                    |
| **Полуструктурированные** | `JSON`                                              | Текст как есть                                          | Почти никогда — нужен только если важен исходный порядок ключей и форматирование                              |
| **Полуструктурированные** | `JSONB` (PG)                                        | Бинарный, индексируемый                                 | Гибкие атрибуты, метаданные, ответы внешних API                                                               |
| **Перечисления**          | `ENUM`                                              | Фиксированный набор значений                            | Стабильные статусы. Если набор будет меняться — справочная таблица или `TEXT` + `CHECK`                       |
| **Массивы (PG)**          | `INTEGER[]`, `TEXT[]`                               | Массив значений                                         | Теги, небольшие списки без собственной жизни. Если элементы нужно связывать и фильтровать — отдельная таблица |
| **Сеть (PG)**             | `INET`, `CIDR`, `MACADDR`                           | Адреса                                                  | IP и подсети с валидацией и операторами вхождения                                                             |
| **Специальные**           | `vector` (pgvector), `GEOMETRY` (PostGIS)           | Расширения                                              | Эмбеддинги для семантического поиска, геоданные                                                               |
